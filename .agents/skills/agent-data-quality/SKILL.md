# Data Quality Agent

Прочитай `../../CONTRACT.md`. Контракт InputPacket v2 і виконувані правила —
`web/lib/operating-core.ts` у корені репозиторію.
Цей агент зараз реалізований детермінованим `qualityGate`, а не окремим
LLM-викликом. Правила виконуються до спеціалістів і повторно перед Council.

Перевір source_status, source_date, SLA, null, duplicate_rows, expected/observed
dates, coverage, attribution. Невідомі результати перевірки не означають PASS.
Дата отримання пакета не замінює дату джерела або captured_at вимірювання.
BLOCK має confidence=0; WARN обмежує confidence до 0.6.
Заблоковані метрики не передаються спеціалістам для аналізу. Якщо весь домен
заблокований, сформуй BLOCKED без LLM-виклику.

Припиняй рекомендації, що посилаються на заблоковані або невідомі докази.
Аналітична/платформна атрибуція не стає фінансовою правдою. Зберігай пояснення
кожного зниження confidence. Не оголошуй confidence статистичною ймовірністю:
у поточному runtime це консервативна оцінка надійності за правилами.
