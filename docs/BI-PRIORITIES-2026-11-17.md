# BI — пріоритети 17.11.2026

## Межі роботи

Єдиний координатор цього циклу — окремий чат BI Барбари. Паралельні спеціалісти мають окремі файли і завершуються після конкретного результату. Нових розкладів немає. Glovo віртуальних закладів, Social, Подаруй пісню та інші проєкти на паузі; план 2027 — після BI. Не змінюємо дизайн. Повернення узгоджених фільтрів/тижнів та усунення зайвих сповіщень не означає приховування помилок якості.

## Черга

1. Продажі / #50, #49: звірити джерело, чинний атомарний importer та receipt. Початкова помилка джерела виправлена власником; старий one-off SQL не застосовувати. Наявна погоджена відкритість Google Sheet не є новим блокером. Зберігати ID запиту при невизначеному результаті, повторювати перевірку статусу, не запуск імпорту.
2. Основні Агрегатори: рік, місяць, бренд, власність, заклад. Фільтри повинні застосовуватись до всіх показників та порівнянь на сервері; не плутати з Glovo.
3. Тижні: ISO 8601, понеділок–неділя, ISO-рік + ISO-тиждень, неповні тижні явно позначати. SQL та клієнт мають збігатися; без цього не вмикати некоректний режим.
4. GBP: помилка провайдера — не профіль і не нульові показники; дата успішних даних не дорівнює даті спроби завантаження. Чотири адреси вже підтверджені власником і зіставлені за точними ID у локальному кандидатові. Не чистити staging/curated чи змінювати sync без окремого плану.
5. Windsor / Meta: встановити доступність і дату бізнес-даних. Платежі й відключення акаунтів не виконувати без рішення власника.
6. Вересневий P&L: джерело AW/AX підтверджене власником; 34 показники додані у локальний snapshot, підсумки розраховує BI. Історія січня–серпня збережена; вересень 2025 відсутній, YoY для неповного порівняння прихований. Деталі — PNL-SEPTEMBER-2026-11-17.md.

## Запуск нового клієнтського сайту

Власник підтвердив: **16.11.2026 о 09:00 Europe/Kyiv**, тобто **07:00 UTC**. Реєстр події — `web/lib/data/business-events.ts`. Це аналітичний контекст, а не завдання втручатися в міграцію сайту.

До: timestamps < межі; після: timestamps >= межі. Для денних джерел **16 листопада — змішаний день**, його не можна повністю приписати старому або новому сайту. Для чистого денного порівняння старий сайт до 15.11 включно, новий з 17.11. Тижні й місяці, що перетинають запуск, також змішані.

Порівнювати однакові дні тижня, тривалість, канали/пристрої та повноту періодів. Відстежувати продажі, sessions, конверсію, якість подій і UTM, швидкість і редиректи; перевірити зміни визначень/тегів. Зміна метрик сама по собі не доводить ефект нового сайту: реклама, промо, сезонність, відключення та неповні джерела — альтернативні пояснення. Якщо доступні продажі лише до 15.11, післязапускового порівняння ще немає.
