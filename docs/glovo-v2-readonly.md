## Джерело і мапінг

Збережено приватний server-only OAuth `spreadsheets.readonly`, `no-store`, обмеження часу/розміру, заборону редиректів та санітизовані помилки. Читається тільки погоджена таблиця: `Дані` gid 1135188423, A5:I до межі grid; `Мапінг закладів` gid 20111302, A1:E; `Мапінг брендів` gid 20111303, A1:G. Кожен діапазон обмежено фактичною кількістю рядків. Ідентичність і розміри всіх трьох вкладок перевіряються до та після читань. Помилкові заголовки, дублікати ключів (навіть непогоджені), зайві колонки, невалідні погоджені значення або зміна grid відхиляють весь звіт.

Лише `Погоджено` впливає на класифікацію. Порожнє/`Очікує` та нові невідомі бренди залишаються UNKNOWN. Ключ бренду — точні сирі бренд × заклад; Excel-рядок є походженням, а не ключем чи ID замовлення. Сирі назви, адреса, рядок, ключ агрегату і причини мапінгу збережені в деталізації. Групування МітБар з v1 збережено; для інших погоджених брендів група дорівнює точній сирій назві, без вигаданих alias.

Погоджені target alias: Ахматова NEW → Ахматова; Оболонь NEW → Оболонь; Теремки NEW → Теремки; Парк Авеню NEW → Парк Авеню; София new → Софія. Реальний/Фізичний → PHYSICAL, Віртуальний → VIRTUAL. Власні/Власний → OWNED; Франчазі/Франшиза → FRANCHISE; Партнерський → PARTNER. Спільна адреса сама по собі не доводить тотожність локацій.

## Формули та повнота

UAH підтверджено власником 13.11.2026. Місяць — `Order Created Local Month`, не глобальний обліковий день; точний timezone та дата останнього замовлення відсутні. Час читання не є свіжістю оригінального експорту.

SHA-256 рахується до нормалізації/мапінгу: кожен сирий A:I рядок місяця перетворюється на JSON; рядки сортуються за цими JSON-рядками стандартним порядком UTF-16; хешується UTF-8 JSON масиву відсортованих рядків. Excel lineage та null беруть участь. Константи D294 не оновлюються автоматично. Невідповідність дає CHANGED/PARTIAL та показує очікуваний і фактичний digest. Листопад не має підтвердження і є PARTIAL. Це підтвердження власника, не незалежний аудит; без фактичного збігу жодний історичний місяць не підвищується до COMPLETE.

Строгі сума та замовлення недоступні, якщо хоча б один вибраний рядок має пропуск відповідної міри. COMPLETE вимагає підтвердження кожного вибраного місяця, наявних рядків та обох строгих підсумків. Чек = сума покупок / замовлення **лише рядків із обома мірами**, за додатного знаменника. UI показує кількості відомих сум, замовлень, пар та типів. Віртуальна частка = сума VIRTUAL / загальна сума × 100; недоступна за невідомого типу або пропущеної суми. Нуль допускається лише як виміряне значення; частка фізичного портфеля без віртуальних рядків дорівнює нулю за повної класифікації.

MoM = поточна сума мінус сума безпосередньо попереднього календарного місяця; % = різниця / попередня сума × 100, лише за додатної бази. Обидва місяці мають бути COMPLETE. Портфель порівнює весь вибраний неперервний діапазон із попереднім рівної довжини. Співставна когорта залишає спільні ключі нормалізований бренд × фізична локація (fallback — заклад джерела); повнота перевіряється до обмеження когорти. Рейтинг — за сумою, із часткою, зваженим чеком та MoM останнього COMPLETE місяця. Внесок бренду = його абсолютний MoM / загальний абсолютний MoM × 100. Відсутній рядок бренду в одному місяці не підміняється нулем: внесок недоступний і сума внесків може не бути 100%.

Фільтри: рік, місяць або від/до, сирий/нормалізований бренд, заклад джерела, фізична локація, тип, власність, стан мапінгу, сортування рядків, режим порівняння. Пріоритет дат явно вказано: окремий місяць → діапазон → рік → default; пропущені місяці неперервного діапазону залишаються PARTIAL. Drilldown зберігає активні фільтри. Матриця показує фактично наявні сирі пари, без декартового добутку віртуальних вітрин.

## Перевірка та межі передачі

Контрольні D294 значення реалізовані як assertions проти обчислених даних, не UI-fallback: 25 887 779,33 UAH; 25 533 замовлення; чек 1 013,89 UAH; віртуальна частка суми 39,94%; останній COMPLETE MoM +263 043,95 UAH / +7,35%. Для кожного показано MATCH / DELTA / UNVERIFIED і фактичну різницю. Суми перевіряються до 0,005001 одиниці (округлення до двох знаків), замовлення — точно.

У цьому runner немає налаштованого Google credential: фактичні цифри, групи/локації/місяці та сумісність алгоритму digest з первинним підтвердженням **не звірені наживо**. Автентифікований rendered parity у Preview не спостерігався. Нативні тести використовують лише синтетичні записи. Необхідний наступний trusted Preview check на SHA, який створить зовнішній runner: перевірити всі digest, шість assertions та групи/локації/місяці без публікації приватних рядків.

`node scripts/glovo-preview-browser.mjs` перевіряє фактичний SSR presenter із CSS на 360/768/1440 локально; це не Preview і не live-source перевірка. У поточному sandbox Chromium не запустився до deadline на 360px (BLOCKED_BROWSER_STARTUP / ETIMEDOUT); адаптивність браузером тут не підтверджено.

Немає ID/статусів окремих замовлень: скасування та дублікати замовлень між локаціями перевірити неможливо. Composite-дублікати агрегатів відхиляються. Google API не надає транзакційного snapshot між фактами та словниками: конкурентні зміни клітинок при незмінних розмірах залишаються ризиком, а зміна фактів історичних місяців анулює digest.

Commit/PR URL і статус exact-SHA Preview встановлює зовнішній trusted workflow після перевірок. У Codex commit, push, PR, merge, deploy, Supabase DDL/DML, імпортери Sales, scheduler, provider та Google edits не виконувались.
